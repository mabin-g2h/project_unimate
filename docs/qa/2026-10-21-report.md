## What was verified working

- **Role matrix** (83 cases, all 39 route files): anonymous gets 307 to /login (only `/api/auth/*` returns 401); students get 401/403 on every admin route; admins reach them; students only see their own data.
- **Hard rule 1:** peer rows contain exactly the whitelisted keys; phone is masked unless opted in; no hashes, tokens, document URLs or rejection data anywhere in peers/me/log-timeline responses.
- **Hard rule 2:** passport and admission letter files are deleted on approve and reject; the profile photo is kept.
- **Auth flows:** signup, verify (single-use, 48h form deadline, expiry deletes account), duplicate/case-insensitive email, ADMIN_EMAIL bootstrap, login, logout, forgot/reset (uniform 200, 1h expiry, single-use), admin invite/accept/revoke/demote.
- **Uploads:** magic-byte sniffing, exact 2 MB/1 MB boundaries, spoofed types, filename traversal (server-generated names), 30 MB body does not crash the server.
- **Lifecycle:** revoke/unrevoke (reason required, HTML-escaped in mail, 500-char cap, hidden from peers), archive sweep (idempotent, one email), cron purge/archive/90-day log prune, abandoned email can re-register.
- **JWT:** wrong-secret, `alg:none`, expired, tampered-payload and garbage tokens are all rejected; cookie is HttpOnly + SameSite=Lax.
- **Injection:** SQL metacharacters in forms, login and filters are inert; CRLF in a name cannot inject a mail header; hostile names render as text in the admin UI and peer cards (no script/element).
- **Logging:** every step appears in Logs and the student timeline; Sent/Failed pills; filters, pagination and date inclusivity; a failed send logs `email_send_failed`.
- **UI:** country-scoped University/City lists reset on country change, "Other" fallbacks, arrival airports scoped by country, "Same flight!" vs "Same day", filters and chips, phone toggle, invite modal, mobile filter drawer.

## Not tested / limits

- Production-only behaviour: `Secure` cookie flag (covered by a unit test only), Vercel body limit (F-23), Vercel-added headers.
- Chromium only; no WebKit/Firefox. No ZAP scan.
- Passport/admission blob deletion was tested against the local-disk driver, not real Vercel Blob.
- The test branch is a copy of production that the guarded setup truncates before every run; production was never written to.
